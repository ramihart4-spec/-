# مجموعة غرزالدين التجارية

تطبيق إدارة متكامل لمجموعة غرزالدين التجارية.

## الرفع على GitHub Pages

1. ارفع هذه الملفات على GitHub repository
2. فعّل GitHub Pages من Settings → Pages → Branch: main
3. سيكون التطبيق على: `https://username.github.io/repo-name/`

## الملفات
- `index.html` — التطبيق الكامل
- `sw.js` — Service Worker للعمل offline
- `manifest.json` — إعدادات PWA
